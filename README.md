# Card Wars

It's the Adventure Time Card Wars Game forked from (ThugRod)[https://github.com/ThugRod/CardWarsOriginal], who modernized the game for newer android devices. Thank you!

This version is a slightly modified version based on my preferences:

 - The screen orientation is locked to Landscape Left instead of Right.
 - You can now buy gems with coins
 - Adjusted daily gift rewards
 - Updated the chest events for 2026-2028 (apparently rewards were based on specific dates)
 - Removed the intro logos for faster startup
